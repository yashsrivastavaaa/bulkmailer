# UI direction

The landing and app use a dark, minimal SaaS visual language inspired by the supplied portfolio reference: restrained monochrome surfaces, strong typography, thin borders, compact data density, subtle gradients, and high-contrast CTAs. The implementation is original and does not copy portfolio assets or text.

Core UX additions:
- Landing page with features, workflow, CTA and legal links.
- Persistent SaaS sidebar with Dashboard, Campaigns, Templates and Settings.
- Excel/CSV upload with exact recipient count.
- Check/uncheck individual recipients, check/uncheck visible rows, search, clear list.
- Paste multiple email addresses separated by spaces, commas, semicolons or new lines.
- Duplicate/invalid address filtering.
- Template storage in PostgreSQL.
- Campaign history in PostgreSQL.
- Google OAuth connection status.
- Attachment handling with validation.
